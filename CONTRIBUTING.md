# Contributing

Thanks for your interest in contributing!

Getting started
- Fork the repo and open a PR.
- Open issues for feature work or bugs before large changes.
- Keep PRs focused; add tests where applicable.

Development
- Frontend: cd frontend && npm install && npm run dev
- Backend: cd backend && dotnet restore && dotnet run

Style & CI
- The repository uses GitHub Actions to build both frontend & backend. Ensure both pass on your branch.

Labels
- enhancement, bug, docs, infra, high-priority
